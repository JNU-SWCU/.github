## 무엇을 하나요

- **프로그램 운영** — 해커톤, 오픈소스 교육, 사전교육 같은 사업단 프로그램의 모집 · 신청 · 심사 · 결과 공개를 한 곳에서 처리합니다.
- **GitHub 자동화** — 참가 팀 저장소 생성, collaborator 초대, 웹훅 연결, 비공개에서 공개로의 전환까지 플랫폼이 직접 관리합니다.
- **참여 기록** — 학생의 커밋 · PR · 이슈 활동을 모아 랭킹과 성과로 남깁니다.

## 저장소

| 저장소 | 설명 |
| --- | --- |
| [`oss-hub`](https://github.com/JNU-SWCU/oss-hub) | OSS Hub 본체. TypeScript 모노레포(웹 + API + GitHub App 연동) |
| [`oss-hub-practice`](https://github.com/JNU-SWCU/oss-hub-practice) | 학생용 실습 저장소. fork · PR · 배포 퀘스트 연습용 |

> 이 조직 아래 이름이 해시로 끝나는 저장소는 프로그램 신청 시 자동 생성되는 **팀 저장소**입니다.

## 참여하기

1. [jnu-oss-hub.com](https://jnu-oss-hub.com)에서 진행 중인 프로그램을 확인합니다.
2. 신청하면 팀 저장소가 이 조직 아래 자동으로 만들어집니다.
3. 기간 동안 작업하고, 심사를 거쳐 결과가 공개됩니다.

## 기여 규칙

- 이슈로 먼저 논의하고, 브랜치를 만들어 Pull Request로 보냅니다.
- 커밋 메시지는 Conventional Commits(`feat:`, `fix:`, `chore:`)를 따릅니다.
- 리뷰 승인 후 `main`에 병합합니다.
